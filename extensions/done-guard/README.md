# done-guard

指示書が指定した出力ファイルの最終行が `DONE` になるまで、Piが終わるのを止める拡張です。

Piは作業者として動かすとき、完了を知らせる専用の手段を持ちません。そのため「結果を `<パス>` に書き、最終行を `DONE` の1行にする」と指示し、待つ側がその `DONE` で完了を知る運用になります。ローカルLLMが `DONE` を書き忘れて終わると、待つ側は完了に気づけません。done-guard はこの書き忘れを機械的に防ぎます。

## 動作

Piが終わろうとする直前（`agent_before_settle`）に、次を行います。

1. 会話のユーザーメッセージ（指示書）から出力ファイルを探す
2. そのファイルの最終行（空行を除く）が `DONE` だけの行か調べる
3. そうでなければ、次の指示を足して作業を続けさせる

> `<パス>` の最終行に DONE の1行を書いてから終えること（書けない事情があれば、その理由を書いたうえで DONE）。

### 出力ファイルの決め方

優先順は次のとおりです。

1. `DONE_FILE: <パス>` または `DONE_FILE=<パス>` の明示
2. 「DONE」を含む行にある、絶対パスか `~/` 始まりの `.md` / `.txt` のパス。同じ行を先に、なければ前後1行を見る

見つからなければ何もしません。`~/` は利用者のホームに展開します。

### 止めない場合

- 差し戻しは、1つの出力ファイルにつき2回までです。それ以降は通します。
- ファイルが無いときは、`DONE` が無いものとして差し戻します。
- ファイルの読み取りがそれ以外の理由で失敗したときは通します（fail open）。
- 中断やエラーで終わるときは通します。
- 差し戻しの回数はセッションの開始で数え直します。

## 導入

```bash
pi install git:github.com/unitea1992/pi-extensions
```

この拡張だけを有効にする設定は、[リポジトリのREADME](../../README.md) を見てください。1回だけ試すなら次のとおりです。

```bash
pi -e git:github.com/unitea1992/pi-extensions
```

## 動作確認

```bash
printf 'DONE_FILE: /tmp/out.md\n/tmp/out.md に「こんにちは」とだけ書いて終えてください。DONE は書かないこと。\n' > /tmp/task.txt
pi -p --no-session -e ./extensions/done-guard/src/index.ts "$(cat /tmp/task.txt)" </dev/null
tail -n 2 /tmp/out.md   # 最終行が DONE になる
```
